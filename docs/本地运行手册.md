# MyJQR 本地运行手册（Windows）

> 目标：从零把项目在你这台电脑跑起来，能注册、能选模板、能流式生成一篇文章。
> 你的机器已具备：Python 3.13 ✅、Node 22 ✅、Git ✅ —— 还缺 MySQL 和 Redis。

---

## 一、资料准备清单（唯一需要你自己去申请的东西）

| 资料 | 必须？ | 去哪拿 | 填到哪 |
|---|---|---|---|
| **DeepSeek API Key** | ✅ 必须（没有它生成不了文章） | https://platform.deepseek.com → 注册 → 充值¥10 → API Keys | `.env` 的 `DEEPSEEK_API_KEY` |
| 智谱 GLM API Key | 建议（DeepSeek 故障时自动降级） | https://open.bigmodel.cn → API Keys | `.env` 的 `ZHIPU_API_KEY` |
| 博查搜索 Key | 可选（联网搜索引用；不填自动跳过） | https://open.bochaai.com | `.env` 的 `BOCHA_API_KEY` |
| 阿里云 AK/SK | 可选（内容审核 M3 才接） | 暂不用管 | — |

**其余全部不需要你准备**：
- 模板库：`docs/焦圈儿模板数据_prmpt.xlsx`（你已填好 54 个提示词）✅
- 分类/种子模板/敏感词/管理员：`app/seeds.py` 内置 ✅
- 提示词导入：`scripts/import_prompts.py` 自动完成 ✅

## 二、环境安装（只缺两样：MySQL + Redis，推荐用 Docker 一次解决）

### 方式 A（推荐）：装 Docker Desktop
1. 下载：https://www.docker.com/products/docker-desktop/ → 安装后重启（需开启 WSL2，安装器会提示）
2. 验证：`docker --version` 有输出即可
3. 只起数据库两个容器（前后端仍本机跑，改代码即时生效）：
   ```bash
   cd C:\Users\飞象\Desktop\JQE\MyJQR
   docker compose up -d mysql redis
   ```
   （compose 已把端口映射到本机 127.0.0.1:3306 / 6379）

### 方式 B（不想装 Docker）：原生安装
- MySQL 8：https://dev.mysql.com/downloads/installer/ 装社区版，root 密码设为 `myjqr_root`（或随意，改 .env 对应）
- Redis：Windows 无官方版 → 装 **Memurai**（Redis 兼容，https://www.memurai.com）或 WSL2 里 `apt install redis-server`

## 三、首次初始化（共 6 条命令，顺序执行）

```bash
# ① 配置环境变量
cd C:\Users\飞象\Desktop\JQE\MyJQR
copy .env.example .env
#    用记事本打开 .env：
#    - 填 DEEPSEEK_API_KEY（必须）
#    - MYSQL_DSN / REDIS_URL 里的主机名 mysql→localhost、redis→localhost（本机直连容器）

# ② 后端依赖
cd backend
pip install -r requirements.txt

# ③ 建表 + 种子数据（15 分类 / 10 内置模板 / 敏感词 / admin 账号）
python -X utf8 -m app.seeds

# ④ 导入你的 54 个提示词模板库（xlsx → 数据库）
python -X utf8 -m scripts.import_prompts
#    先看看会导入什么（可选）：python -X utf8 -m scripts.import_prompts --dry

# ⑤ 启动 API（开发热重载）
uvicorn app.main:app --reload --port 9000

# ⑥ 另开一个终端启动 ARQ worker（真正调模型干活的进程）
cd C:\Users\飞象\Desktop\JQE\MyJQR\backend
arq app.tasks.worker.WorkerSettings
```

前端（再开两个终端）：
```bash
cd C:\Users\飞象\Desktop\JQE\MyJQR\apps\web   && npm i && npm run dev    # 用户端 http://localhost:8080
cd C:\Users\飞象\Desktop\JQE\MyJQR\apps\admin  && npm i && npm run dev   # 后台    http://localhost:8081/admin/
```
（两个前端都已把 `/api` 代理到 localhost:9000，无需额外配置）

## 五、常见问题

| 现象 | 原因与解法 |
|---|---|
| `Can't connect to MySQL` | 容器没起或 .env 没把 `mysql` 改成 `localhost`；`docker compose ps` 看状态 |
| 生成一直"准备中"没输出 | ARQ worker 没启动（终端⑥），或 `.env` 没填 DEEPSEEK_API_KEY |
| 生成直接报错 `no provider available` | 两个模型 key 都没配 |
| 接口 401 跳回登录 | token 过期（2小时），重新登录即可 |
| 中文乱码 | 命令行加 `-X utf8` 参数（手册命令已带） |
| 3306/6379/9000 端口占用 | `netstat -ano | findstr :3306` 找到 PID，任务管理器结束，或改 compose 端口映射 |
| 想重置全部数据 | `python -X utf8 -m app.seeds`（会清库重建）再跑导入脚本 |

## 六、日常二次启动（不用再初始化）

```bash
docker compose up -d mysql redis        # 数据库
cd backend && uvicorn app.main:app --reload --port 9000   # 终端1
cd backend && arq app.tasks.worker.WorkerSettings          # 终端2
apps/web  → npm run dev                                    # 终端3
apps/admin → npm run dev                                   # 终端4
```

> 提示词更新后重新导入：改 xlsx → `python -X utf8 -m scripts.import_prompts`
> （内容没变的模板自动跳过，变了的模板生成 v2 版本并自动发布，历史版本保留可回滚）
