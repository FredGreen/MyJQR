# 项目开发计划：AI 写作平台（Web 版）

> 版本 V1.0 ｜ 2026-10-11 ｜ 配套《06-技术设计说明书》使用（技术栈以 06 为准，本文档管"做什么、谁做、何时完成"）

---

## 1. 项目范围

**做（Web 版 MVP → V1.0）**
- 用户端 PC 网页（Vue3）：模板市场、一键生成（SSE 流式）、追问打磨、AI 率检测报告、降AI率、草稿箱、灵感中心、兑换码充值、个人中心
- 管理后台（Vue3）：模板/分类/提示词版本管理、用户与焦耳管理、兑换码管理、内容审核队列、数据看板、系统配置
- 后端（Python FastAPI）：全部业务 API + SSE + ARQ 异步任务
- 基础设施：MySQL、Redis、Milvus、阿里云 OSS、阿里云内容安全、博查搜索、DeepSeek + GLM 双模型、Docker Compose 部署

**不做（本期明确排除）**
- iOS / Android App（API 已按无状态 REST+SSE 设计，未来加客户端只需换壳）
- UGC 模板上架、社区信息流、关注关系（二期）
- 微信/支付宝在线支付（**一期用兑换码**：零资质零成本验证商业模式；拿到营业执照后二期接支付，见 §7）

**三个默认决策**（当时提问未获答复，按最稳妥执行，可随时调整）：
1. 排期按 2~3 人小团队编制，附单人裁剪指引（§4）；
2. 支付一期兑换码、二期在线支付；
3. 登录一期账号密码+邮箱（预留手机号验证码/微信扫码扩展位）。

## 4. 单人开发裁剪指引（周期约 5~6 个月）

若只有一个人：**保 M0/M1/M2/M3/M5 全部 + M4 仅兑换码**，砍掉 4.2~4.5（灵感中心、看板、Milvus 应用）。顺序：先跑通"裸生成链路"（hardcode 模板 → DeepSeek 流式 → 页面打字机，1 周内见到第一个端到端效果，建立信心），再按 M1→M2→M3 补工程化。**每周五保持主干可演示**。

## 5. 关键路径与风险

| 风险 | 影响 | 对策 |
|---|---|---|
| **ICP 备案 2~4 周** | 上线延期 | M0 第 1 天提交；期间用 IP+临时域名内测 |
| 生成式 AI 合规（网信办） | 通报下架 | 全量机审+人审队列；页面标注"AI 生成"；尽早启动算法备案 |
| AI 率检测不准 | 核心卖点失灵 | 三层检测；对外展示区间值；黄金集持续校准 |
| 双模型同时故障 | 服务不可用 | DeepSeek↔GLM 互备；队列削峰重试 |
| 提示词被竞品复刻 | 资产流失 | 提示词永不下发客户端（详情接口只回 usage_example） |
