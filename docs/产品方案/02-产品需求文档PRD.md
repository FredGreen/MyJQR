# 产品需求文档（PRD）：AI 写作平台（对标焦圈儿）

> 版本 V1.0 ｜ 2026-10-11 ｜ 产品形态：iOS App（上架 App Store）+ Web 创作工作台

---

## 1. 产品概述

### 1.1 一句话定位
"选一个写作滤镜，输入一句话，得到一篇像人写的、能过 AI 检测的文章。"

### 1.2 目标用户与核心场景

| 用户 | 场景 | 付费意愿 |
|---|---|---|
| 公众号/头条号作者（主） | 日更压力：选题→成文→排版→降AI率 | 高（订阅+焦耳） |
| 小红书/知乎创作者 | 爆文笔记、高赞回答 | 中高 |
| 职场人/学生 | 周报、演讲稿、论文降AIGC | 中（按次） |
| 市场/销售/公关 | 软文、通稿 | 中 |

### 1.3 北极星指标
周活跃生成用户数（WAGU）；辅：模板使用渗透率、检测通过率（>70%）、次周留存。

### 1.4 与焦圈儿的差异化策略（选 1~2 项做深）
- **垂直化**：只做公众号长文（焦圈儿全品类），把"排版直发公众号"做透；
- **结果可验证**：把"AI率检测报告"做成生成流程的一环（生成→检测→不达标自动重写），比焦圈儿"手动降AI"体验更顺；
- **价格战**：新人免费额度翻倍 + 模板定价更低。

## 3. 核心流程与验收标准

### 3.1 主流程：模板生成
```
选模板 → 输入主题(≤200字, 可附原文/链接) → [联网搜索][深度思考]开关 → 扣焦耳(预冻结)
→ SSE: search_start → search_end → thinking_delta(阶段) → text_delta(正文)
→ 检测报告(AI率 X%) → [免费重写(若≥阈值)] / [定向降AI] / [追问] / [复制/保存草稿]
```
验收标准：
- 单篇 2000 字生成 ≤ 90s（P50）；
- 断网重连可续传或恢复草稿；
- AI 率展示误差与腾讯朱雀官网比对 ±10% 内；
- 失败自动退还冻结焦耳。

### 3.2 计费流程
- 生成前**冻结**焦耳 → 成功落扣 / 失败解冻；余额不足引导充值（iOS 拉 IAP）。
- 定价锚点（参照焦圈儿）：轻量模板 100J、精品长文 1000J、降AI率 1000J、重生成 5J；¥10=100J。

## 4. 提示词资产体系（产品经理最重要的准备工作）⭐

> 你说"不知道要准备什么提示词"——答案：**提示词是本产品的商品本体**，PM 要像商品经理管理 SKU 一样管理提示词库。

### 4.1 模板卡片（每个模板一份"模板定义文档"）

对齐我们逆向出的字段，每张卡片包含：

| 字段 | 说明 | 示例 |
|---|---|---|
| name / category | 名称与分类 | 故事会/读书 |
| system_prompt | 系统提示词（核心资产，版本管理） | 见 4.3 |
| user_prompt_template | 用户输入装配模板 | `主题：{topic}\n素材：{material}\n字数：{length}` |
| model + params | 绑定模型与参数 | deepseek-chat, temperature=0.9 |
| enable_web_search / enable_think | 开关 | 长文默认双开 |
| output_format | 输出结构 | 标题+导语+正文(小标题)+金句+结尾 |
| usage_example | 使用示例（详情页展示） | "输入：瑞幸分析 → 输出：……" |
| usage_tips | 使用提示（详情页展示） | "附上你的观点，AI味更低" |
| joule_price | 定价 | 1000 |
| eval_set | 评测集（≥20 条真实主题） | 见 4.4 |

### 4.3 必备的 8 类系统提示词（PM 要逐个写出来）

1. **文体人格化提示词**（每个模板的核心）：人设+文风+口头禅+禁忌；
2. **反AI味约束**（注入每个模板）：见 4.5 的 8 特征清单；
3. **选题/标题生成**：热点→10 个爆款标题（悬念/数字/反差/借势 4 式）；
4. **大纲生成**：主题→3~5 个备选大纲（供"阶段进度"展示与用户干预）；
5. **追问改写**：基于上下文的局部重写（保持其余段落不动）；
6. **降AI率定向重写**：输入段落+检测报告→仅改写高风险句；
7. **排版转换**：MD→公众号富文本（标题样式/引用块/分隔线规范）；
8. **安全兜底**：涉政涉黄赌毒拒答与改写（所有模板前置注入）。

### 4.4 提示词评测体系（上线前必须建立）

- **黄金集**：每模板 ≥20 条真实主题（从目标用户社群收集）；
- **三维打分**：① 朱雀/AIGC 检测通过率（目标 ≥70% 人工特征）② 可读性人工盲评（1~5 分，≥3.5）③ 事实错误率（联网引用核对）；
- **回归测试**：每次改 prompt 版本跑全量黄金集，分数下降禁止发布（写进 CI）；
- **线上回流**：用户"免费重写"率 >30% 的模板自动告警，进入迭代池。

### 4.5 去 AI 味的 8 大特征与修正策略（写进每个模板的硬约束）

| AI 特征 | 修正策略（提示词约束） |
|---|---|
| 连接词堆砌（首先/其次/总之） | 限制显性连接词，用语义衔接 |
| 段落结构机械等长 | 强制段落长短错落（3~9 句随机） |
| 总分总模板化 | 要求"场景/故事切入，不写总起句" |
| 举例公式化（比如…） | 要求用"我见过/去年有个读者"式个人化案例 |
| 词汇华丽空洞 | 禁用"赋能/抓手/闭环/ unveils"等高频AI词表 |
| 缺乏口语与语气词 | 注入"说白了/讲真/你猜怎么着"等口语标记（按文体配额） |
| 观点平庸骑墙 | 强制二元立场+反例让步 |
| 标点完美规整 | 允许破折号、省略号、短句成段 |

> 另需一份《AI高频词黑名单》（约 200 词）作为提示词附录与后处理兜底。

## 6. 合规与上架要求（中国 + App Store）

### 6.1 国内合规（生成式 AI 类产品硬门槛）
1. **ICP 备案**（域名+App 双备案）；
2. **算法备案/生成式AI服务备案**（网信办，焦圈儿有备案号；周期 2~3 个月，材料含：安全评估报告、模型来源说明、审核制度）——建议 MVP 开发期并行启动；
3. **内容安全**：先审后显（AI 生成内容机审+人审队列）、敏感词库、违法不良信息举报入口；
4. 用户实名（手机号）、青少年模式、年龄分级 13+。

### 6.2 App Store 审核（AI 内容类高频被拒点）
1. 虚拟商品（焦耳/订阅）必须 IAP，不得引导外部支付（Guideline 3.1.1）；
2. 接入第三方登录（微信）必须同时提供 **Sign in with Apple**（4.8）；
3. UGC/社区功能必须有：举报、拉黑、内容过滤（1.2）——若二期才做社区，一期就不放任何 UGC 入口；
4. AI 生成内容需有内容过滤机制（1.2），应用描述勿宣称"绕过检测/作弊用途"（合规话术：**"提升人机协作写作的自然度"**，不提"过朱雀/绕过检测"——焦圈儿 App Store 文案就写了"低朱雀AI检测率"，存在下架风险，我们不要学）；
5. 隐私营养标签、隐私政策链接、账号删除入口（Apple 要求可注销）。
