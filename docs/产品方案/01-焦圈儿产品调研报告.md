## 2. 功能全景（逆向 + 公开信息拼出的完整清单）

### 2.2 模板市场（UGC 生态）

- 模板有 **author 字段**（逆向确认）→ 用户可自建模板并分享；
- **一键"做同款"**：看中别人的成品文章，直接套用其模板；
- **复刻提示词** + **提示词权限**（不公开/不可见/支付可见）→ 提示词成为可交易的数字资产；
- 模板带 score 评分、user_count/use_count 使用统计、热门内容 TOP3 展示（逆向确认 stats 结构）；
- 分类体系：选题/新闻/科技/教育/情感/军事/文化/数码/财经/读书/影视/美食/游戏/旅游/口播 共 15 类（逆向确认，见 Excel）。

### 2.3 灵感中心（选题）

- 主流媒体实时热点 + 站内频道热点选题；
- AI 选题深度解析（模板 id=10000"今日选题"：给关键词 → 生成爆款标题/选题）。

### 2.4 社区（App Store 类别=社交的原因）

- **转圈**、**追问** 特色交互；#话题 tag、频道聚类；
- 关注/推荐/最新信息流、个人主页定制（头像/封面/数据）；
- 发布：智能排版、自动生成标题、分享长图；
- 创作激励：被引用积累影响力、点赞外收益、"主流媒体掘金计划"对接四大平台。

### 2.6 生成过程交互（SSE 协议逆向）

生成走 SSE 流式推送，事件序列（实测抓包）：

```
event: search_start   → {query, metadata:{provider:"bocha", queries:[3个子查询]}}
event: search_end     → {references:[{title,url,summary,site_name,publish_time}...]}
event: content_block_delta → {delta:{type:"thinking_delta", stage:"progress", text:"构思与大纲规划..."}}
event: content_block_delta → {delta:{type:"text_delta", ...}}   # 正文逐字
event: content_block_stop
```

"思考阶段"文案（构思大纲→分析资料→验证权限→筛选整合→初稿→润色→排版→验收）为**预定义阶段标签批量推送**，属于进度条体验设计，非真实推理流。协议命名模仿 Anthropic 流式 API。

## 3. 版本演进史（产品迭代路线的最好参照）

| 阶段 | 版本 | 关键动作 |
|---|---|---|
| 冷启动 | 0.3~0.6（2025.10-11） | 基础写作、发现页、多轮追问、个人主页 |
| 留存 | 0.8~0.9（2025.12-2026.1） | 标注划线、联网搜索、MD增强、**模板市场+做同款** |
| 变现 | 0.12~1.0（2026.2-3） | 草稿箱、灵感中心、**人工率检测**、多格式复制 |
| 壁垒 | 1.1~1.3（2026.4-7） | **降AI率Agent、AI率补偿、批量生成**、智能排版发布 |

> 规律：先用"社区+模板"拉留存，再上"检测/降AI率"建立技术壁垒和付费点。

## 4. 技术实现线索（逆向所得）

- API 风格：REST `/api/v1/*`，JWT(RS256) Bearer 鉴权，cursor 游标分页（page 参数无效，page_size 上限 20）；
- 模型配置随模板下发：`recommend_config{model, model_display_name, enable_web_search, enable_think}`；
- 搜索：博查 Bocha API（bochaai.com），主题→3 子查询→references；
- 内容实体 hot_contents 有独立 content_id（11 位随机串）→ 生成物入库可被引用/展示；
- 图片资源：img.jiaoquaner.com（模板头像）、OSS（用户头像）；
- Web 工作台与 App 共用 api-server.jiaoquaner.com。

## 5. 商业模式小结

**获客**：降AI率刚需（知乎"降AI率的神"）+ 新人免费额度 + 邀请裂变。
**变现**：订阅（会员等级/赠焦耳/专属通道）+ 焦耳消耗（按模板定价，质优模板贵）+ 提示词交易（复刻付费可见）。
**壁垒**：① 降 AI 率的提示词工程与检测闭环 ② 模板 UGC 生态 ③ 垂类模型路由（按文体选模型）。

## 6. 用户反馈（App Store 评论）

- 正面：多模型集成、追问打磨好用；
- 负面：找不到客服、更新后不显示 AI/人工率、部分设备无法登录。
- 教训：检测结果的展示稳定性、客服触达渠道是口碑关键。

---

## 7. 对我们的启示

1. **MVP 必须有**：模板化生成（10~20 个精品模板）+ 联网搜索 + 流式进度体验 + 焦耳计费 + 基础检测；
2. **差异化可选**：降 AI 率作为 Pro 能力；模板市场/社区放二期；
3. **合规前置**：焦圈儿拿到了算法备案——生成式 AI 类产品在国内上架的硬门槛，需提前 2~3 个月启动；
4. **iOS 全链路用 IAP**（虚拟商品强制），Web 端可微信/支付宝直付。
