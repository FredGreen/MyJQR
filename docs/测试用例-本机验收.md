# MyJQR 本机验收测试用例

> 配套可执行脚本：`backend/scripts/acceptance_test.py`（后端起好后一键跑全部用例）
> 运行方式：`cd backend && python -X utf8 -m scripts.acceptance_test`
> 前置条件：mysql/redis 容器运行中、API(9000) 与 ARQ worker 已启动、`.env` 已填 DEEPSEEK_API_KEY
>
> **首轮执行记录（2026-10-17）**：首轮 12/18 → 修复 4 个问题后 **18/18 全部通过**。
> 首轮暴露并已修复：① generate 投递 ARQ 用 arq 默认 1s 连接超时必 500（新增 `app/core/redis.py`）；
> ② 投递失败不退款导致焦耳冻结卡死（generate 增加失败兜底）；③ `llm.py` 流式调用用错 httpx API
> （`client.post` → `client.stream("POST")`，存量 bug）；④ 兑换码重复使用 404→409。
> 另发现两个测试环境坑：worker 不随 .env 热更新（须重启）、旧 worker 进程重复启动了多个。

## 用例清单

| # | 用例 | 操作 | 预期结果 |
|---|---|---|---|
| TC01 | 服务健康 | GET /health | code=0 |
| TC02 | 注册送焦耳 | POST /auth/register（随机邮箱） | code=0，签发 token |
| TC03 | 登录 | POST /auth/login | code=0，返回 tokens |
| TC04 | 分类列表 | GET /template/category/list | 15 个分类 |
| TC05 | 推荐列表+游标翻页 | GET /template/recommend/list（两页） | 首页 20 个、has_more=true，第二页不重复 |
| TC06 | 模板详情·提示词不泄露 | GET /template/detail | 有 usage_example/tips；**无** system_prompt/user_prompt 字段 |
| TC07 | 分类下模板列表 | GET /template/list?category_id=N | code=0，条目带 rank |
| TC08 | 收藏/取消收藏 | POST + DELETE /template/{id}/bookmark | is_bookmarked 先变 true 再变 false |
| TC09 | 初始焦耳余额 | GET /joule/me | balance=100（注册赠送） |
| TC10 | 生成全链路（100J） | POST /works/generate → 读 SSE stream | 出现 stage→delta(多个)→report→done；作品 status=done、有字数；余额 100→0 |
| TC11 | SSE 断线续传（重放） | done 后再 GET stream?seq=0 | 重放出全部历史事件（Redis 30min 缓存） |
| TC12 | 余额不足拦截 | 余额 0 时再生成 | HTTP 402，提示焦耳不足，不产生新作品 |
| TC13 | 管理员登录 | POST /admin/login（admin） | code=0，签发 admin token |
| TC14 | 看板总览 | GET /admin/dashboard/overview | code=0，返回用户/模板/作品统计 |
| TC15 | 批量生成兑换码 | POST /admin/redeem-codes/batch（1000J×1） | 返回 1 个兑换码 |
| TC16 | 兑换码充值 | POST /joule/redeem | 余额 +1000；重复兑换同码 → 409 |
| TC17 | 焦耳流水 | GET /joule/transactions | 含 freeze/settle/redeem 类型记录 |
| TC18 | 作品列表/详情 | GET /works、GET /works/{id} | 列表含刚生成的作品；详情有正文与 AI 率报告 |
